# Srijana - BCA Project Showcase Website

A simple, responsive **College Project Showcase** website built for a BCA 6th semester project using plain **HTML, CSS, and JavaScript**.

## Student Details

- **Name:** Srijana
- **Program:** BCA (Bachelor of Computer Applications)
- **Semester:** 6th Semester
- **Project Type:** College Project Showcase Website

## Features

- Responsive single-page layout (desktop, tablet, mobile)
- Sticky navigation with mobile menu toggle
- Active section highlighting on scroll
- Project details and feature highlights
- Contact form with client-side validation and demo success message
- Clean, modern UI with no external frameworks required

## Technologies Used

- **HTML5** - page structure
- **CSS3** - styling, layout, and responsive design
- **JavaScript** - navigation behavior and form validation
- **Google Fonts (Inter)** - typography

## Project Structure

```text
personalproject/
├── index.html        # Main website page
├── css/
│   └── style.css     # Styles and responsive layout
├── js/
│   └── script.js     # Menu, scroll highlight, form validation
└── README.md         # Project documentation
```

## How to Run

No installation is required.

1. Download or clone this project folder.
2. Open the `personalproject` folder.
3. Double-click `index.html` to open it in your web browser.

Alternatively, you can open it with a local server (optional):

- **VS Code Live Server:** Right-click `index.html` → *Open with Live Server*

## Customization

You can easily personalize the site by editing:

- `index.html` - name, project title, description, and contact details
- `css/style.css` - colors, fonts, spacing, and layout
- `js/script.js` - form behavior and interaction logic

## Notes

- The contact form is a **demo** form. It validates input in the browser and shows a success message, but it does not send data to a server.
- This project is intended for academic/demo purposes.
